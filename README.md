## Student identity design
Registration uses:
1. **Nama**
2. **ID pelajar** chosen by the learner, with automatic availability check
3. **PIN / Password** — exactly **6 digit number**

The chosen public ID is for login/display. The backend creates a separate immutable internal UUID used for all D1 relationships and learning records.

## Shared device
One phone/browser can remember several learner cards. Remembered cards store only name + public Student ID. Selecting a learner requires that learner's PIN and creates a new scoped session.

A friend/sibling on the same phone does not automatically become linked to Parent Area.

## Parent Area
Parent/guardian has a separate guardian account and Parent Code. Children appear only through explicit `guardian_students` links. Existing children link using a one-time six-digit Link Code generated by the child account.

## Architecture
`GitHub -> Cloudflare Workers (static assets + API) -> Cloudflare D1 -> custom domain`

Key files:
- `index.html` — frontend PWA
- `manifest.json` — PWA manifest
- `sw.js` — offline/cache behaviour
- `src/index.js` — Cloudflare Worker API/runtime/auth
- `wrangler.jsonc` — Cloudflare Worker + D1 configuration
- `db/schema.sql` — D1 application/auth schema
- `scripts/verify-static.mjs` — repository contract/static check
- `.github/workflows/verify.yml` — CI verification for source/frontend/schema contracts
